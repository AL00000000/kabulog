06条件と限界

  • 帯の分け方：500億円以下を1つの帯にし、500億円超を銘柄数が同じになるよう4等分しました。500億円以下が500億円超のほぼ2倍あるため、500億円以下と同じ銘柄数では上に刻めません。
  • 対象：プライム・スタンダード・グロースの内国株です。ETF、REIT、優先株、起点より後に上場した銘柄は除きました（前半64銘柄、後半43銘柄）。
  • 騰落率：Yahooの分割調整済み終値で計算し、配当は含みません。
  • 時価総額は概算：基準日の終値に現在の発行済株式数を掛けています。その後に増資した銘柄は過大になります。
  • 上場廃止の抜け：銘柄リストが2026年5月末時点より新しいものだけなので、1〜5月に廃止された銘柄は入っていません。影響の大きさは測っていません。
  • 平均は急騰銘柄に引っ張られます：比較には中央値も併せて見てください。
  • 対象期間：2026年の約10か月・2期間だけです。他の年でも同じかは検証していません。
