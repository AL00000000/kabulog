2022.09 — 2026.10 ／ 売買代金10億円以上の新高値 ／ 毎日 資産の1/5を入れ替え

新高値を毎日買い続けたら

「その日に新高値を付けた銘柄を資産の5分の1で毎日均等に買い、資金は成績の悪い銘柄から売って作る」という機械的な運用を、 日足から約4.1年ぶん再現しました。比べる相手は同じルールで、新高値の代わりにくじ引きで選んだ銘柄（20回）と、TOPIX連動ETF（1306）です。 結論から書くと、新高値で選ぶとくじ引きより明確に悪く、TOPIXにも大きく負けました。

01運用マニュアル（このとおりに実行すれば同じ結果になる）

本人と相談して決めたルールです。他のAIや人がこのページだけを読んで再現・運用できるよう、判断が分かれうる点はすべて書いています。

A. 毎営業日の手順（大引け 15:30 に行う）

  1. 新高値銘柄を確定する。対象は東証プライム・スタンダード・グロースの株式（ETF・REIT等は除く）で、その日の売買代金が10億円以上のもの。そのうち当日高値 ＞ 当日を含まない直近365日の最高値になった銘柄が「52週新高値」。同値は更新に数えない。さらに上場来の最高値（月足の当月より前＋当月の当日より前の日足）以上なら「上場来新高値」。どちらで運用するかは最初に1つ決めて途中で変えない。
  2. 新高値が0件なら何もしない。売りも買いもしない。
  3. 予算を決める。予算 ＝（現金 ＋ 保有株をその日の終値で評価した時価）× 1/5。毎日その日の資産で計算し直す（初期資産の1/5に固定しない）。
  4. 現金が予算以上なら、売らずに現金だけで買う（始めの数日はこれになる）。現金が足りなければ、不足額のぶんだけ売る。
  5. 売る銘柄の選び方。
    • 売れるのは、保有銘柄のうちその日の新高値リストに入っていない銘柄だけ。今日の新高値銘柄は売らない（今日買い増す対象なので）。
    • 平均取得単価からの騰落率（終値÷平均取得単価−1）が低い順、つまり成績が悪い順に売る。値上がりしている銘柄しか残っていなくても、上昇率の低いものから売る。
    • 1銘柄を丸ごと売っても不足額に届かなければ次の銘柄へ。最後の銘柄は不足額ちょうどだけ一部売却する。
    • 売買停止などでその日の終値が無い銘柄は、その日は売らない（評価は直前の終値）。
  6. 売っても予算に届かなかった場合（保有がほぼ今日の新高値銘柄ばかりの日）は、作れた金額だけで買う。借りてまで買わない。
  7. 買う。使える金額を新高値銘柄の数で均等に割り、全銘柄をその日の終値（大引け）で買う。既に持っている銘柄なら買い増し、平均取得単価を加重平均で更新する。
    例：資産1,000万円・新高値20銘柄 → 予算200万円 → 1銘柄10万円ずつ。現金が30万円なら170万円ぶんを成績の悪い順に売って作る。
  8. 予算を作る以外の理由では売らない。損切り・利益確定・保有期間の上限は無い。上場廃止で値が付かなくなった銘柄は、最後の終値で現金化したものとして扱う。

B. 前提として無視しているもの

  • 最小投資単位（100株単位）— 端数株でも買える前提。
  • 手数料・税金・スリッページ・ストップ高で買えないこと。
  • 本人の実際の資産額 — 初期資産は便宜上1,000万円・全額現金から開始。結果は比率で読む。

C. 新高値の判定で気をつけること（ここを外すと結果が変わる）

  • 株探ランキングの株価は15:24時点で終値ではない。終値・売買代金は引け後の日足（Yahoo Finance）で確定させる。
  • 「上場来」は厳密にはYahooが持つ全期間（多くは2000年前後から）。月足が取れない銘柄は上場来を判定せず対象外にする（「5年来」を上場来と誤認しないため）。
  • 上場から30営業日未満の銘柄は判定しない（比べる過去がほぼ無く、何でも新高値になるため）。
  • Yahooの日足には桁が壊れた値や2日続く異常値が混じる。前後5本の中央値から外れて戻る値は除去してから判定する（backfill_newhigh.clean_bars）。

D. 実装（このリポジトリで再計算する手順）

py rebuild_newhigh_history.py --fetch      # 全銘柄の日足2年分（約20分）
py kensho_newhigh/simulate.py              # 売買シミュレーション → docs/data_kensho_newhigh/result.json
py kensho_newhigh/forward_returns.py       # §03 の表 → docs/data_kensho_newhigh/forward.json
py kensho_newhigh/april_to_0623.py         # §04 の表 → docs/data_kensho_newhigh/april.json

日別の新高値リストは docs/data_newhigh/YYYY-MM-DD.json（新高値タブと同じもの）。長期の検証はこのリストではなく日足から毎日判定し直している（実記録は2026-07-30開始のため）。判定ロジックは fetch_newhigh.py と同一で、実記録のある51日で再現率99.5%を確認済み。

02結果 — 資産の推移

03なぜ負けるのか — 新高値の「その後」

売買ルールが悪いのか、新高値という選び方が悪いのかを分けるために、くじ引きの対照群を置きました。同じ日・同じ銘柄数を、その日の売買代金10億円以上の銘柄から無作為に選び、まったく同じルールで売買したものです。

実測新高値を付けた銘柄は、翌日・5日後・20日後のどの時点でも母集団全体より成績が悪い（中央値・上昇した割合とも）。 40日後・60日後（約2〜3か月）になると上場来新高値は母集団に追いつき、中央値ではわずかに上回る（60日後 +2.69% 対 +2.43%）。52週新高値は60日後でも下回ったまま（+1.81%）。 推論このルールは「新高値の日の引けで買い、その後に下がった銘柄から売る」ので、買った直後に押し戻されやすい新高値銘柄では、高値で買って小さく負けて売るを毎日繰り返すことになります。売却時の騰落率の中央値がマイナス、勝率が3割台なのはこの裏付けです。くじ引きの銘柄は買った直後に下がる癖が無いので、同じルールでも資産が増えています。

04参考: 2026年4月の新高値を6/23まで持っていたら

相場が強かった時期（日経平均は4/1〜6/23で約+30%）の1例です。4月の各営業日に新高値を付けた銘柄を、その日の引けで買い、6/23の引けまで持った場合です。

実測この期間に限れば、新高値銘柄は同じ日の母集団全体より明確に良く、上場来新高値は中央値でもTOPIXを上回りました。 注意ただしこれは1つの期間・1回の観測で、強い上げ相場の中です。§03の約4.1年の平均では2〜3か月持っても差はほぼ無く、悪い相場では新高値の方がはっきり不利でした（新高値タブの検証）。この1例を一般化しないでください。

05この結果を割り引くべき点

長期の母集団には生存バイアスがある

2022〜2026年の検証に使った日足は、いま上場している銘柄（＋2026年6月時点の一覧）が中心です。途中で上場廃止になった銘柄の多くが入っていません。新高値側にも対照群側にも同じように効くので比較は成り立ちますが、絶対値は実際より良く出ている可能性があります。

くじ引きの結果は大きくばらつく

成績の悪いものから売るルールでは、たまたま大きく上がった銘柄に資産が集中していきます。そのため20回の抽選でも結果の幅が広く（表の「範囲」）、中央値で比べています。それでも本番は20回のほぼすべてを下回りました。

6/23以降の期間は短く、一部が再現データ

約4か月・86営業日しかありません。新高値リストのうち35日は記録が無く、日足から後日再現したものです（実記録との一致率99.5%）。

売買代金は「終値×出来高」で近似

株探の売買代金（約定代金の合計）とは少しずれ、10億円の境目の銘柄が入れ替わることがあります。

コストを入れていない

毎日資産の2割を入れ替えるので、手数料・スプレッドを入れると本番はさらに悪くなります（対照群も同様）。
